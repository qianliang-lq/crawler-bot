## 1. 结论（三句话）

1. **两站同属 `csrc_search_list`**：壳页 `#list` 皆空；列表数据应由 `GET /searchList/{channelid}?_isJson=true&…`（及抽样中的 `/common/searchList/{channelid}`）提供。  
2. **同一 `CsrcSearchListAdapter` 即可**：只换 `channelid` + `org_prefix`（`szzyb`/`shzyb`）+ `column_code`（`c101700`/`c101682`）。  
3. **详情 URL 模式**：`https://www.csrc.gov.cn/{org}/{column}/c{manuscriptId}/content.shtml`（JSON 中常为协议相对 `//www.csrc.gov.cn/...`）。

## 4. 详情 URL 模式

由 `url` + `manuscriptId` 归纳：

```text
https://www.csrc.gov.cn/{org_prefix}/{column_code}/c{manuscriptId}/content.shtml
例：https://www.csrc.gov.cn/szzyb/c101700/c7652321/content.shtml
沪办预期：https://www.csrc.gov.cn/shzyb/c101682/c{manuscriptId}/content.shtml
```

详情模板 meta：`ArticleTitle`, `PubDate`, `ContentSource`；正文容器走 `detail-to-markdown`。

## 5. 本轮 live 复测（限速 ~0.25–0.3 rps）

| 请求 | 结果 |
|------|------|
| SZ/SH 壳页 GET | **TLS EOF** → meta `000`（本 box 出口不稳） |
| `/searchList/{channelid}` | TLS EOF `000` |
| `/szzyb\|shzyb/searchList/...` | **302** nginx HTML；`Set-Cookie: acw_tc=…`；`Location: http://www.csrc.gov.cn`（WAF 味） |
| `/common/searchList/{channelid}`（SZ+SH） | 同上 **302** + `acw_tc` |

**解释**：今日出口被拦，**不否定**此前 14:06–14:07 抽样的 200 壳页 + 合法 searchList JSON。技能与 Adapter 应：优先 HTTP；失败升档 headed+HAR；执行面放稳定/内网出口。未做打码、未绕防护。
